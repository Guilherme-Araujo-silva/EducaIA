# EducaIA

Assistente virtual baseado em IA generativa e RAG (Retrieval-Augmented Generation) para responder dúvidas sobre uma plataforma educacional fictícia.

## Objetivo

O projeto utiliza uma base de documentos institucionais como fonte de conhecimento para que o assistente consiga recuperar informações relevantes e gerar respostas contextualizadas.

## Base de conhecimento

Os documentos utilizados nesta primeira etapa são:

- Regimento do Estudante
- Política de Reembolso de Matrículas
- FAQ sobre Cursos e Certificados
- Guia de Uso da Plataforma
- Programa de Bolsas e Afiliados

## Fluxo planejado

1. Coleta e organização dos documentos
2. Extração e processamento do conteúdo
3. Geração de embeddings e indexação vetorial
4. Recuperação de informações relevantes (RAG)
5. Geração e validação das respostas
6. Desenvolvimento da interface
7. Deploy na Oracle Cloud Infrastructure (OCI)
